# Дорожная карта Project Aurora

Этот документ описывает план развития проекта **Project Aurora** — операционной системы будущего. 🌌

---

## 📍 Текущая версия: v0.1.0 (Alpha)

**Статус:** Начальная разработка  
**Дата:** Сентябрь 2026

---

## 🎯 Цели проекта

- Создать модульную, расширяемую операционную систему с открытым исходным кодом
- Обеспечить безопасность и прозрачность на уровне ядра
- Предоставить сообществу инструменты для экспериментов с архитектурой ОС
- Построить экосистему драйверов, приложений и утилит

---

## 🗺️ Этапы развития

### v0.1.0 — Alpha (Сентябрь 2026 — Декабрь 2026)

**Цель:** Базовое ядро и загрузчик

- [x] Инициализация репозитория
- [x] Настройка сборки (Makefile, CMake)
- [ ] Загрузчик (Bootloader)
- [ ] Минимальное ядро (защитный режим, GDT, IDT)
- [ ] Базовый вывод на экран (VGA, framebuffer)
- [ ] Обработка прерываний
- [ ] Документация архитектуры

**Критерии завершения:** Система загружается и выводит текст на экран

---

### v0.2.0 — Pre-Alpha (Январь 2027 — Март 2027)

**Цель:** Управление памятью и базовые драйверы

- [ ] Менеджер памяти (paging, heap, stack)
- [ ] Многозадачность (планировщик, контекст)
- [ ] Драйвер клавиатуры (PS/2, USB)
- [ ] Драйвер диска (ATA, AHCI)
- [ ] Файловая система (FAT32, ext2)
- [ ] Базовая оболочка (shell)

**Критерии завершения:** Можно загрузить файл с диска и выполнить команду

---

### v0.3.0 — Developer Preview (Апрель 2027 — Июнь 2027)

**Цель:** Сеть и многопользовательский режим

- [ ] Сетевой стек (TCP/IP, UDP)
- [ ] Драйвер Ethernet (PCIe, virtio)
- [ ] Пользовательские режимы (ring 0/3)
- [ ] Системные вызовы (syscall)
- [ ] Базовый API для приложений
- [ ] Менеджер процессов

**Критерии завершения:** Система поддерживает сеть и изолированные процессы

---

### v0.4.0 — Beta (Июль 2027 — Сентябрь 2027)

**Цель:** Графический интерфейс и приложения

- [ ] Графическая подсистема (GUI)
- [ ] Драйвер мыши
- [ ] оконный менеджер
- [ ] Базовые приложения (терминал, текстовый редактор, файловый менеджер)
- [ ] Динамическая линковка (shared libraries)
- [ ] Пакетный менеджер

**Критерии завершения:** Можно запустить GUI-приложения

---

### v1.0.0 — Stable Release (Октябрь 2027 — Декабрь 2027)

**Цель:** Первый стабильный релиз

- [ ] Стабильное ядро
- [ ] Полная документация
- [ ] Тесты и CI/CD
- [ ] Поддержка виртуальных машин (QEMU, VirtualBox)
- [ ] Поддержка физического железа (список совместимых устройств)
- [ ] Сообщество разработчиков

**Критерии завершения:** ОС готова для повседневного использования разработчиками

# Project Aurora
**Операционная система будущего** 🌌
Независимый open-source проект по разработке операционной системы с нуля.
---

## 📖 О проекте
**Project Aurora** — это образовательный и исследовательский проект, цель которого — создать модульную, расширяемую операционную систему с открытым исходным кодом.

### Особенности
- 🔓 **Открытый исходный код** — лицензия MIT
- 🧪 **Экспериментальная архитектура** — свобода для инноваций
- 📚 **Образовательная цель** — изучение устройства ОС изнутри
- 🤝 **Сообщество** — вклад может внести каждый
---

## ⚠️ Примечание о названии
Этот проект **не связан** с российской мобильной операционной системой «Аврора» (Aurora OS), 
разрабатываемой компанией «Открытая мобильная платформа».
**Project Aurora** — это независимый образовательный open-source проект, 
созданный энтузиастами для исследования архитектуры операционных систем.
---

## 🚀 Быстрый старт
### Требования
- Компилятор: GCC или Clang
- Сборщик: Make или CMake
- Эмулятор: QEMU (для тестирования)
- Язык: C / C++ / Rust (в зависимости от твоего стека)

### Сборка
```bash
git clone [https://github.com/ТВОЙ_НИК/project-aurora.git](https://github.com/ТВОЙ_НИК/project-aurora.git)
cd project-aurora
make
```

### Запуск в QEMU
```bash
qemu-system-x86_64 -kernel build/aurora.bin
```

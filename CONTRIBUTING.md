## Как начать
### 1. Изучите проект (а ещё лучше участвуйте в их написании)

- Ознакомьтесь с [README.md](README.md) — общее описание проекта
- Посмотрите [документацию](docs/) — архитектура, API, руководства
- Изучите открытые [Issues](../../issues) — текущие задачи и баги

### 2. Выберите задачу
- Ищите метки `good first issue` — подходят для новичков
- Метка `help wanted` — задачи, где нужна помощь сообщества
- Хотите предложить своё? Создайте новый [Issue](../../issues/new) с описанием идеи

### 3. Сделайте форк и ветку
```bash
# Форкните репозиторий через GitHub UI
git clone [https://github.com/ТВОЙ_НИК/aurora-os.git](https://github.com/ТВОЙ_НИК/aurora-os.git)
cd aurora-os
git checkout -b feature/твоя-фича
```

### 4. Внесите изменения
- Следуйте стилю кода проекта (см. [STYLEGUIDE.md](docs/STYLEGUIDE.md), если есть)
- Пишите понятные коммиты: `feat: добавить драйвер USB`, `fix: исправить утечку памяти`
- Добавляйте тесты для нового функционала

### 5. Отправьте Pull Request
```bash
git push origin feature/твоя-фича
```
- Создайте PR через GitHub UI
- Опишите, что делает ваша фича
- Укажите связанные Issues (например, `Closes #123`)
